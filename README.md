# AI-Based Cosmetics Purchase Prediction

## Project Overview

This project uses Artificial Intelligence and Machine Learning techniques to predict whether a customer will purchase a new unisex skincare/cosmetics product.

The project also analyzes customer age groups to identify the group with the highest expected number of buyers.

## Objectives

1. Predict customer purchase behavior using machine learning classification models.
2. Analyze customer demographics and purchasing patterns.
3. Compare machine learning models based on evaluation metrics.
4. Identify the age group with the highest expected number of buyers.
